# SMEFlow Demonstration Script

## Opening

Hello. My name is Naziru Sanusi Inuwa, and this is my 3MTT Airtel-NextGen Full-Stack Development capstone project, SMEFlow.

SMEFlow is a digital operations management platform designed to help small and medium-sized enterprises organise customers, tasks and useful resources in one place.

## Demonstration

1. Open the deployed application.
2. Create a user account.
3. Log in.
4. Show the dashboard.
5. Add a customer.
6. Edit the customer.
7. Search for the customer.
8. Create a task.
9. Change the task status.
10. Edit and delete a task.
11. Add a business resource.
12. Search the resource.
13. Show the responsive interface.
14. Briefly show the GitHub repository and project structure.
15. Show the final deployed application.

## Closing

The project demonstrates a complete development flow from a business problem to a full-stack solution, including frontend development, backend APIs, database integration, authentication, testing and deployment.
